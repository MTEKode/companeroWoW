# CompaneroWoW

Addon para World of Warcraft.

## Instalación (desarrollo)

Copia o enlaza la carpeta `CompaneroWoW/` dentro de `World of Warcraft/_retail_/Interface/AddOns/`.

## Estructura

- `CompaneroWoW/CompaneroWoW.toc` — manifiesto del addon.
- `CompaneroWoW/CompaneroWoW.lua` — punto de entrada.
